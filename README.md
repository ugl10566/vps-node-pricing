## 先分清：免备案vps不等于"随便用"

几个经常被绕过去的前提，先摆在前面。

**免备案通常只指服务器所在地**。香港、美国、日本、韩国、德国这些境外机房不需要走ICP备案流程；国内机房（江苏宿迁、湖北十堰、浙江宁波、广东深圳、重庆等）只要绑域名对外提供访问，备案是绕不过去的。

**免备案和内容合规是两回事**。境外机房一般没有国内那套前置审核，但服务商自己的服务条款依然管用。涉及违规内容，商家照样能停你的机器。

**低价套餐的带宽和流量往往有隐含条件**。看到"不限流量"先翻到底部，通常写的是限速策略——比如流量跑完后降到1M或5M，想恢复高速得单独买流量包。

境外机房之间最大的差别不是硬盘大小，是国内访问绕不绕路。

香港节点离得近，走三网直连或CN2这类线路时，延迟能压到几十毫秒，国内用户打开页面的感受接近本地服务器。代价是带宽小、单价高，同样配置通常比美国贵一截。

## 常见问题

**免备案vps需要实名吗？**
雨云是国产服务商，注册和购买环节有实名认证要求。免备案指的是服务器不用走ICP备案，和账号实名不是一回事。

**香港节点带宽只有3M、5M，够用吗？**
看你放什么。文字博客、API接口、后台管理完全够；图片站、视频站、下载服务建议直接看香港四区或洛杉矶。带宽是香港节点最贵的资源，把它花在对的地方。

**流量跑完之后会怎样？**
流量叠加型的套餐用完额度后会限速，可以通过购买流量包恢复高速，未用完的流量通常会自动结转到下个月。

**能随时换配置或换区域吗？**
购买后可以按天补差价升级套餐、扩容云盘、增购独立IP，部分区域支持迁移。
